# Round 18 事前登録 — ロングオンリー・ポートフォリオ研究

**登録日:** 2026-10-04（コミットハッシュは本 PR の最初のコミットを参照）  
**目的:** ウォッチリスト由来の長期ロングオンリー構成が、**年率約10%** をどれだけ安定して狙えるかを、**研究のみ**（サイト非掲載）で検証する。  
**設計者:** Emma（Round 18）。

## 固定パラメータ（本コミット以降変更しない）

### データ・実装

- 価格: Yahoo Finance **調整後終値**（既存 `fetchDailyBars`、range=`max`、十分な `keep`）。
- ベンチマーク: **SPY**, **SOXX**, **QQQ**（同じ価格源）。
- 口座: 初期 **$3,200**、**整数株**のみ。リバランス日の終値で約定、売却代金は同日再投資可とする。
- 手数料: 約定 **1回あたり** $0.35 および $1.00 の **2通り**を記録。構成の**選択**（in-sample）は **$0.35** 固定。
- 銘柄の上場: 調整後日足の **最初の取引日 ≤ リバランス日** のときのみユニバースに含める（以降は通常保有可）。
- **ONDS は一切含めない**。`src/lib/paper.ts` は変更しない。CSV・秘密情報はコミットしない。

### ユニバース（現在の `data/watchlist.yaml`）

1. ウォッチリスト全銘柄から開始。
2. **除外:** ONDS、セクター `financials`、テーマ **quantum / space（SPCX 以外）/ crypto（CORZ 含む）/ solar / nuclear**（`src/lib/themes.ts` と `themeOf` に一致）。
3. **黒字のみ:** 実行時点の `resolveProfitability`（Yahoo trailing EPS / TTM 純利益 → なければ EDGAR TTM）。**全期間にその判定を適用**（履歴時点の黒字は未実装 → **ルックアヘッド・バイアス**として結果に明記）。
4. **サバイバーシップ:** ユニバースは **今日のウォッチリスト**（過去に上場廃止・リスト外の銘柄は含まない）。

### セクター上限（リバランス後の**目標ウェイト**に適用し、超過分を比例削減して再正規化）

| バケット | 上限 |
|---|---|
| `semi` + `equipment` 合算 | **30%** |
| その他の各 `watchlist` グループ id ごと | **30%** |

（`semi` と `equipment` は二重カウントしない。）

### 構成法（4種）× 銘柄数 N × リバランス

| 構成法 | 銘柄の選び方（リバランス日） | ウェイト |
|---|---|---|
| `equal` | 時価総額（下記）上位 **N** | 各 **1/N**（セクター上限後再正規化） |
| `mcap` | 時価総額上位 **N** | 時価総額比例 |
| `invvol` | 時価総額上位 **N** | 直近 **60営業日**年率ボラの逆数比例 |
| `momentum` | **12か月リターン − 直近1か月**（21営業日スキップ）上位 **N** | 各 **1/N** |

- **N ∈ {10, 20, 30}**
- **リバランス:** 各 **月首営業日** / **四半期首営業日** / **年首営業日**（NYSE 営業日カレンダー）

**時価総額近似:** 調整後終値 × **直近 EDGAR 発行済株式数**（取得不可時は Yahoo の `sharesOutstanding` スナップショット × 価格）。履歴の株式数は更新しない → **バイアス**として明記。

### 期間

| 区分 | 期間 | 用途 |
|---|---|---|
| In-sample | **2016-01-01 ～ 2020-12-31** | 構成の**選択**（2018 後半・2020/3 を含む） |
| Out-of-sample | **2021-01-01 ～ 2026-10-02** | 選択した構成を**固定**して評価 |

### In-sample 選択規則（$0.35 手数料）

36 通り（4×3×3）を in-sample でバックテストし、次の順で **1つ**を選ぶ:

1. in-sample **CAGR** 最大
2. 同点は in-sample **最大DD** が浅い（ドルベースのピークからの下落率が小さい）
3. さらに同点は `equal` → `mcap` → `invvol` → `momentum`、N 小→大、リバランス annual → quarterly → monthly の辞書順

（in-sample で SPY より DD が浅いことは**選択条件には含めない**；pass 判定は OOS のみ。）

### 合格基準（事前登録・OOS 2021-2026-10-02）

1. **CAGR ≥ 10%**（年率、OOS 期間の日次評価額）
2. **最大DD** が同期間 **SPY より浅い**（同じ定義）
3. **暦年リターン**が **2017, 2018, …, 2026（YTD ～10/02）** の **10年のうち少なくとも7年がプラス**（選択構成で **2017-01-01 から**運用した系列）

**参考線（合格ではない）:** OOS CAGR **≥ 12%** および **≥ 13%** を併記（「現実的に10%を狙う」ためのサバイバー・バイアス調整の目安）。
