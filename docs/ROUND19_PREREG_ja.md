### 時価総額（ウェイト・plain 選定用）

- **リバランス日 `d` の時点**のみ:  
  `mcap = 終値(d) × 発行済株式数`  
- 株式数: SEC EDGAR **companyfacts** の **当該日より前**の最新 filing  
  - `dei:EntityCommonStockSharesOutstanding` または  
  - `us-gaap` の加重／期末発行済株式（実装で優先順を固定）。  
- **Yahoo / yfinance の現行 marketCap・sharesOutstanding は履歴に使わない。**
- 株式数が `d` に無い場合: **直近過去の株式数を繰り越し**（レポートに **銘柄数・ウェイトの何 % が繰り越し株数か** を記載）。

### 選定（selection）× ウェイト（weighting）の直積

**選定**（N ∈ {15, 20}、四半期）— 各リバランスでホールディング銘柄を決める:

| 選定 ID | 規則 |
|---|---|
| `corrdiverse` | 252 日相関・平均相関昇順 greedy、既選と **ρ > 0.7** はスキップ |
| `volprune` | ρ > 0.7 ペアでボラ高い方を除外後、上記 greedy |
| `plain` | 候補のうち **時点 mcap 上位 N** |

**ウェイト**（小数株、選定後に適用）:

| ウェイト ID | 規則 |
|---|---|
| `mcap` | 時点 mcap 比例 |
| `mcap_cap10` | mcap 比例のあと **単一銘柄上限 10%**、超過は **比例配分で再分配** |
| `mcap_cap5` | 同上 **上限 5%**（別バリアント） |
| `equal` | 等ウェイト |
| `invvol` | 60 営業日年率ボラの逆数比例 |

**適用順:** ウェイト計算 → **単一銘柄上限**（cap 系のみ）→ **半導体+装置 30% 上限**（GICS Sub-Industry 定義は従来どおり）。

**試行構成数:** 3 選定 × 2 N × 5 ウェイト = **30**（ID 例: `corrdiverse_15__mcap_cap10`）。

### In-sample 採用規則（2016-01-01 ～ 2020-12-31・$0.35・**1 構成のみ**）

1. IS **最大 DD が SPY（同期間）より浅い**構成のみ残す。  
2. 残りから **IS 年率リターン（CAGR）最大**を **採用（adopted）**。  
3. 同点は **ターンオーバーが低い**方（リバランス間の平均片道ターンオーバー = Σ|Δw|/2 の期間平均）。

採用構成は **変更せず** OOS（2021-01-01 ～ 2026-10-02）を **1 回だけ**評価。
