# Round 19 事前登録 — Saka Index（Emma 個人 ETF 研究）

**登録日:** 2026-10-04（**本ファイルのコミット以降**にバックテスト・成果物を生成する）  
**目的:** 約 **10% 年率 CAGR**、**最大 DD が SPY より浅い**、**15–20 銘柄**・**四半期リバランス**・**小数株**のロングオンリー指数を研究（**サイト非掲載**）。  
**設計者:** Emma（Round 19）。

## 固定パラメータ（本コミット以降変更しない）

### データ・口座

- 初期資金 **$3,200**（Round 18 と同額）。
- 価格: **調整後終値**。取得は Yahoo Finance（既存 `fetchDailyBars`、`range: "20y"`, `keep: 3200`）および **yfinance 相当の欠損銘柄**（削除・上場廃止銘柄は可能な限り補完）。欠損は下記「保守的扱い」。
- **ユニバース（サバイバーシップ除去）:** **時点 S&P 500 構成銘柄**のみ。ソース: GitHub **`fja05680/sp500`** の `sp500_ticker_start_end.csv`（各ティッカーの S&P 加入日・除外日）。リバランス日 `d` では `start_date ≤ d` かつ（`end_date` 空または `end_date ≥ d`）の銘柄のみ候補。
- GICS セクター／業種: 同リポジトリの **`sp500.csv`（現行表）** をティッカー→GICS に使用（**履歴 GICS は未整備 → 現行分類のルックアヘッド**として明記）。
- **ONDS は含めない**（候補から除外）。`src/lib/paper.ts` は変更しない。CSV・秘密情報はコミットしない。

### 保守的な欠損扱い

- **選択時:** 調整後終値がリバランス日に無い銘柄は **候補から除外**（欠損一覧・件数・候補に占める割合をレポート）。
- **保有中の上場廃止:** 最終取引日の終値で **評価を固定**（その後リターン 0%。**ペナルティ**として解釈に記載）。感度分析はレポートで 1 段落。

### 除外（リバランス日の候補から）

1. **赤字:** リバランス日以前に確定した **直近 12 か月純利益 ≤ 0**（EDGAR `companyfacts` の四半期純利益を遡って TTM 集計。取得不可は **候補から除外**＝保守的）。
2. **金融:** GICS Sector = `Financials`。
3. **テーマ（現行 `themeOf` と同じ定義）:** quantum、space（**SPCX 除く**）、crypto／BTC マイナー、 solar、 nuclear。
4. 上記のほか、価格・黒字判定で候補に入れない銘柄。

### セクター上限

- **半導体 + 半導体装置**（GICS Sub-Industry が `Semiconductors` または `Semiconductor Materials & Equipment`）の合計ウェイト **≤ 30%**（超過分は比例削減して再正規化）。

### リバランス

- **四半期**（NYSE 営業日カレンダー上の **四半期初の最初の営業日**、Round 18 `quarterly` と同じ定義）。
- 小数株可。各リバランスで目標ウェイトへ **全売却→再購入**（購入本数分の手数料を先に控除してから配分）。

### 手数料（IBKR ティアードの近似）

- 約定 **1 回あたり** **$0.35**（ベース）と **$1.00**（ストレス）。
- **年間手数料ドラッグ:** 暦年ごとの約定回数 × 単価 を合計し、**$** と **口座平均評価額に対する %** を報告（初期 $3,200 基準の参考も併記）。

## 候補構成（8 通り・IS で 1 つ選択）

いずれも **N ∈ {15, 20}**、リバランス **四半期**。ウェイトは選定後にセクター上限を適用。

| ID | 選び方 | ウェイト |
|---|---|---|
| `corrdiverse_15` / `_20` | 候補全員から: 直近 **252 営業日**日次リターンの相関。平均相関 **昇順**で greedy 追加、既選との **ρ > 0.7** はスキップ（Round 18 CORR 一次ルール同一） | 等ウェイト |
| `volprune_15` / `_20` | 候補で **ρ > 0.7** ペアは **ボラ高い方を除外**後、上記 greedy | 等ウェイト |
| `equal_15` / `_20` | 候補のうち **時価総額（終値×EDGAR 発行済株数、不可は株数=1）上位 N** | 等ウェイト |
| `invvol_15` / `_20` | 選び方は **equal と同じ（mcap 上位 N）** | 直近 **60 営業日**年率ボラの **逆数比例** |

**試行構成数:** **8**（OOS では選択 1 構成のみ固定。全 8 の IS/OOS 指標も表で併記）。

### In-sample 選択規則（2016-01-01 ～ 2020-12-31・手数料 $0.35）

1. IS 期間の **最大 DD が SPY（同期間）より浅い**構成だけ残す。
2. 残りから **IS CAGR 最大**を採用。
3. 同点は **IS 最大 DD が浅い**方（下落率の絶対値が小さい）。

選んだ構成を **変更せず** OOS（2021-01-01 ～ 2026-10-02）で評価。

### ベンチマーク

- **SPY**, **QQQ**（100% 配分・同じ価格源）。**SOXX** は参考。

### 指標

- CAGR、最大 DD、**DD 回復日数**（その DD の直前ピークに戻る営業日数）。
- **暦年リターン:** 各年のリターンは **前年最終営業日の終値**から **当年最終営業日**まで（SPY 2017 ≈ +21.7%、2018 ≈ −4.5% と整合する定義）。
- 暦年プラス率: **2016 ～ 2026（2026 は YTD ～10/02）** の年数に対するプラス年の割合（合格は **≥ 70%**）。

### 合格基準（OOS・$0.35）

1. **CAGR ≥ 10%**
2. **最大 DD < SPY**（同期間）
3. **暦年プラス率 ≥ 70%**（上記 11 年窓）
