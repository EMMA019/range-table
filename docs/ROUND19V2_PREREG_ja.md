## 3. セクター予算（ポートフォリオ・ウェイト）

**semis+tech** = GICS セクターが `Information Technology`、またはサブ業種が半導体（`isSemiSubIndustry`、サブ業種文字列が `semiconductor` を含む）。IT 以外の半導体サブ業もこのバケットに入れる。

| 制約 | 値 |
|---|---|
| semis+tech のポートフォリオ・ウェイト | **最小 15%・最大 30%** |
| それ以外の各 GICS セクター | **最大 25%**（下限なし） |
| 名前数 N | **15 と 20**（別セル） |

スロット（名前数）はウェイト予算に揃える。`n` は 15 または 20。

1. バケット時価総額は、その日の eligible のうち mcap>0 の合計。
2. semis+tech の生スロット = `round(n × techMcap / totalMcap)`。空なら 0。
3. 名前が足りる限り `clamp(生スロット, ceil(0.15×n), floor(0.30×n))`。バケット人数が下限未満なら、取れる人数まで（下限未達を許容し、結果で実ウェイトを報告）。
   - n=15 → スロット下限 3、上限 4
   - n=20 → スロット下限 3、上限 6
4. 残り席は他セクターへ。各セクター上限は `min(そのセクターの人数, floor(0.25×n))`（n=15 なら 3、n=20 なら 5）。
5. 配分は最大剰余法（Hamilton）。同点の剰余はセクター名の昇順で先に席を渡す。上限の合計が残り席に届かないときは **総数が n 未満のまま**（枠を他セクターへ融通しない）。
6. 処理順（全ポートフォリオ相関のときだけメンバーシップに影響）: **semis+tech を先**、その後は eligible 時価総額の降順、同点はセクター名昇順。

ウェイト計算の後に、同じ 15–30% / 25% を **金額ウェイト**へ射影する（§5 の後）。名前スロットだけでは inverse-vol や mcap が予算を破るため。

## 4. 相関 prune（ρ > 0.7）

| 項目 | ロック |
|---|---|
| 推定 | 252 営業日の対数収益、日付を揃えた Pearson（`buildCorrInputs` / `correlationMatrix`） |
| 最小観測 | 126。足りないペアは **違反にしない**（ρ = 0 扱い） |
| 閾値 | **ρ > 0.7 で落とし**（≥ ではない）。v1 の `SAKA_CORR_PAIR_MAX = 0.7` と同じ不等号 |
| 落とし方 | ランク順の貪欲。悪い方を採用しない（同点で両方は取らない） |

ランク（良い方が先）:

- `quota_*`: 対 SPY **252 営業日**相対トータルリターン（`P_t/P_{t-252} − SPY_t/SPY_{t-252}`）の降順 → mcap 降順 → ティッカー昇順。252 日が無い名前は −∞（最後）。
- `mcap_*`: mcap 降順 → 同じ相対モメンタム降順 → ティッカー昇順。

設計ごとの適用範囲（各セルがどちらを使うかは ID に含まれる）:

| 接頭辞 | 相関の範囲 |
|---|---|
| `quota_within` / `mcap_within` | **セクター（バケット）内だけ**。他バケットとの ρ では落とさない |
| `quota_port` / `mcap_port` | **ポートフォリオ全体**。既に採用したどの名前とでも ρ>0.7 なら不採用。空いた席は同じバケットの次点だけで埋める。他バケットからは補わない |

within はバケット間で独立。port は §3.6 のバケット順。出力の保有リストはティッカー昇順で固定する（ウェイトは ID で決まるので順序非依存）。

## 5. ウェイト（5 種・すべて必須）

保有集合が決まってから正規化し、合計 1 にする。

| ID | 定義 |
|---|---|
| `equal` | 各保有 `1/H`（H = 実際の保有数） |
| `mcap_cap5` | PIT mcap 比例のあと `applySingleNameCap(..., 0.05)` |
| `mcap_cap10` | 同じく上限 **0.10** |
| `invvol` | 60 営業日の対数収益の年率標準偏差の逆数。系列が無い名前はウェイト 0。全員欠けるときは equal |
| `atr_er` | 14 営業日の **パーセント ATR** の逆数。`ATR% = mean(|C_i−C_{i−1}| / C_{i−1})`。ドル ATR ではない（ポートフォリオのイコールリスク）。欠測時は invvol と同じ |

単一銘柄キャップは v1 の `applySingleNameCap`（超過分をキャップ未満へ再配分し、最後に合計 1 へ再正規化）。**n=15 かつ 5%** は `15×5% < 100%` なので、全員がキャップに当たると再正規化で **約 6.67%** まで戻る。ハードキャップにして現金を残すことはしない。実現した最大ウェイトを結果で報告する。

その後、セクター射影を最大 32 回:

1. semis+tech が 30% 超、または他セクターが 25% 超なら、そのバケットを上限まで縮小。
2. semis+tech が (0, 15%) なら 15% まで拡大し、非 tech を比例縮小して合計を 1 にする。tech 名前がゼロなら下限は課さない。
3. 合計が 1 からずれた分は、上限未満のバケットへ比例配分。配る先が無ければ再正規化。
4. `mcap_cap5` / `mcap_cap10` は、セクター射影の各周回のあとにもう一度単一銘柄キャップを掛ける（最大 8 周）。最終的に合計 1。

## 7. 主評価 — 案① 年次再選定（PRIMARY）

毎年 1 月、**直前の 3 暦年だけ**で 40 セルから 1 つを選ぶ。その `config_id` をその暦年の四半期リバランス全部に使う。口座はリセットしない。

| 選択月（最初の SPY セッション） | 学習窓 | 保有する OOS 年 |
|---|---|---|
| 2019-01 | 2016-01-01 ～ 2018-12-31 | 2019 |
| 2020-01 | 2017-01-01 ～ 2019-12-31 | 2020 |
| 2021-01 | 2018-01-01 ～ 2020-12-31 | 2021 |
| 2022-01 | 2019-01-01 ～ 2021-12-31 | 2022 |
| 2023-01 | 2020-01-01 ～ 2022-12-31 | 2023 |
| 2024-01 | 2021-01-01 ～ 2023-12-31 | 2024 |
| 2025-01 | 2022-01-01 ～ 2024-12-31 | 2025 |
| 2026-01 | 2023-01-01 ～ 2025-12-31 | 2026（～ 2026-10-02） |

学習窓のシミュレーションは各セル独立、開始時現金 $3,200、差分、$0.35。窓の端は SPY カレンダー上で `from` 以上の最初のセッションと `to` 以下の最後のセッション。CAGR・最大 DD は `metricsFromCurve`（最大 DD は 0 以下の符号付き）。SPY の最大 DD は同じ窓のバイ＆ホールド（手数料なし、初日終値を 1 として正規化）。

**選択規則（学習窓）**

1. 最大 DD が SPY より厳密に浅いセルだけ残す。符号付きなので `config.maxDrawdown > spy.maxDrawdown`。
2. その中で **CAGR 最大**。
3. 同点は **ターンオーバー最小**。
4. まだ同点なら **config_id の辞書順で先**。
5. 1 を満たすセルがゼロのときだけフォールバック: 符号付き最大 DD が最大（いちばん浅い）→ CAGR 最大 → ターンオーバー最小 → id。その年は `fallback=true` と報告する。フォールバックは合格基準を緩めない。

連鎖 OOS は **2019 年の最初の SPY セッションから 2026-10-02** まで 1 口座。年が変わる 1 月リバランスで config_id を切り替える。2016–2018 は学習にだけ使い、連鎖曲線には入れない。

## 9. 合格基準（連鎖 OOS・$0.35）— 実行前に固定

判定は案①の連鎖曲線だけ。小数の丸め前の値で判定し、表示は百分率 1 桁を併記する。

| # | 基準 | 判定への使い方 |
|---|---|---|
| 1 | 連鎖 OOS CAGR **≥ 15%** | 合格 / 不合格 |
| 2 | 連鎖 OOS 最大 DD が **SPY より浅い** かつ 絶対値 **≤ 20%**（`maxDrawdown ≥ -0.20`） | 合格 / 不合格。加えて絶対値が **15% 以上 20% 以下**（`-0.20 ≤ maxDrawdown ≤ -0.15`）かを **報告のみ**（帯の外でも、浅い側なら基準 2 自体は合格になり得る） |
| 3 | 連鎖曲線の暦年プラス率 **≥ 70%**。対象年は 2019–2026 の定義できた年。2026 は 2025 最終セッション → 2026-10-02。プラスはリターン > 0 | 合格 / 不合格 |
| 4 | 連鎖 OOS CAGR **> SPY CAGR** か | **はい / いいえ（報告のみ。不合格にしない）** |

4 項目とも表にする。1–3 がすべて合格のときだけ「案①合格」。
